# Installation Guide - Floating Clock Extension

## Quick Installation (Brave Browser)

### Step 1: Download Extension Files
Download or clone the `Clock_IN_TAB_Space` folder to your computer.

### Step 2: Open Brave Extensions
1. Open Brave browser
2. Type `brave://extensions/` in the address bar
3. Press Enter

### Step 3: Enable Developer Mode
1. Look for the toggle switch in the top-right corner
2. Turn on "Developer mode"

### Step 4: Load Extension
1. Click the "Load unpacked" button
2. Navigate to where you saved the `Clock_IN_TAB_Space` folder
3. Select the folder and click "Select Folder"

### Step 5: Verify Installation
- You should see the Floating Clock icon in your toolbar
- Visit any website to see the clock overlay in the bottom-right corner

## Alternative Installation Methods

### Chrome Browser
1. Navigate to `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked"
4. Select the `Clock_IN_TAB_Space` folder

### Edge Browser
1. Navigate to `edge://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked"
4. Select the `Clock_IN_TAB_Space` folder

## First Time Setup

1. **Click the extension icon** in your toolbar
2. **Customize your settings**:
   - Toggle the clock on/off
   - Choose 12-hour or 24-hour format
   - Enable Focus Mode for better concentration
   - Try Lock Screen mode for enhanced visibility

3. **Position the clock**:
   - Click and drag the clock to move it anywhere on screen
   - Your position is automatically saved

## Troubleshooting

### Extension Not Loading
- Make sure you selected the correct folder containing `manifest.json`
- Try refreshing the extensions page
- Restart the browser

### Clock Not Visible
- Check if the extension is enabled in the extensions page
- Click the extension icon and ensure "Enable Clock" is toggled on
- Try refreshing the webpage

### Permissions Issues
- Ensure the extension has necessary permissions
- Try removing and re-loading the extension
